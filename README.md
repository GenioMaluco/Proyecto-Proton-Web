# Proyecto Proton

Repositorio unificado de **Proyecto Proton**, con las herramientas de narración y los materiales editoriales del libro.

- `Proyecto Proton.txt`: manuscrito usado por las herramientas.
- `Proyecto-Proton/`: capítulos, personajes, ilustraciones, manuscrito compilado y ediciones EPUB/DOCX.
- `proyecto_proton/biblia_personajes/`: fichas e índice de personajes para la narración.
- `proyecto_proton/outputs/MiAudiolibro/`: audios generados por capítulo.
- `biblia_personajes.py`, `Creador_Capitulos.py` y `narrador.py`: herramientas del libro.

## Dependencias

Instala las dependencias de narración con:

```powershell
python -m pip install -r requirements.txt
```

Para compilar el manuscrito de capítulos, consulta [`Proyecto-Proton/README.md`](Proyecto-Proton/README.md).
