# Proyecto Proton

Materiales y herramientas de trabajo del libro **Proyecto Proton**.

- `Proyecto Proton.txt`: manuscrito.
- `proyecto_proton/biblia_personajes/`: fichas e indice de personajes.
- `proyecto_proton/outputs/MiAudiolibro/`: audios generados por capitulo.
- `biblia_personajes.py`, `Creador_Capitulos.py` y `narrador.py`: herramientas del libro.

## Dependencias

Instala la dependencia de narracion con:

```powershell
python -m pip install -r requirements.txt
```
